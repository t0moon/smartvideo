一、项目背景
随着大模型、多模态模型及视频生成模型的发展，AI 已具备生成高质量视频内容的能力。然而，目前市面上的 AI 视频产品仍存在以下问题：
• 以 Prompt 为中心，缺少完整的视频生产流程；
• 缺少 Human in the Loop，无法满足企业审核需求；
• 无法管理长期项目，修改成本高；
• 缺少资产沉淀，每次生成均需重新构建内容；
• 无法与企业 IM（飞书、企业微信等）结合。
因此，本项目设计并实现一个面向企业的视频生产平台，通过 Workflow、Agent、Human in the Loop 和 Asset Library，实现完整的视频生产闭环。
￼
二、产品定位
定位：
企业级 AI 视频生产平台（AI Video Production Platform）
产品目标：
利用 AI Agent 自动完成视频创作，并通过人工审核保证内容质量，实现视频生产自动化，同时沉淀企业创意资产。

AI 自动解析：

• 视频长度

• 品牌
• 平台

        ▲           ▲

        │

        │
        ▼

        │
        ▼

        │
        ├── Save Workspace (snapshot)
        ├── Save Assets (asset library)

这套架构的数据流

我建议整个系统的数据流固定为：

          HTTP / IM
               │
               ▼
         API Gateway
               │
               ▼
         Workflow Config           ← 读取 workflows/*.yaml 决定执行路径
               │
               ▼
        Workflow Runtime
               │
               ▼
      ┌─────────────────────┐
      │  Middleware Chain    │  ← registry 按序执行 tracing / guardrails / approval / retry
      │  (before each step)  │
      └──────────┬──────────┘
                 │
                 ▼
            Context Builder
             ▲           ▲
             │           │
        Workspace     Asset Center
                 │
                 ▼
            Lead Agent           ← 装载当前阶段的 skill + tools
                 │
                 ▼
       ┌─────────────────┐
       │  Guardrails      │  ← 合规检查（广告法 / 品牌禁忌 / 内容安全）
       │  (step output)   │
       └─────────────────┘
                 │
                 ▼
       ┌─────────────────┐
       │  Subagents       │  ← 并行场景生成（复用 deerflow.subagents.executor）
       │  (parallel)      │
       └─────────────────┘
                 │
                 ▼
       Model Router → Tools → Providers
                 │
                 ▼
      ┌─────────────────────┐
      │  Middleware Chain    │  ← pipeline hooks: save workspace / save assets /
      │  (after each step)  │     publish event / trace / pause for review / audit
      └─────────────────────┘
                 │
                 ▼
         ┌───────┴───────┐
         │               │
    Continue Step    Pause for
    (next step)     Human Review
                     (feishu/wecom/slack)
